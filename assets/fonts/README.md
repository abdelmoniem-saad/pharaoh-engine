# Fonts

Bundled for offline use. These are UI design choices, not identified Erza3 brand fonts.

- Barlow Condensed Bold: https://github.com/google/fonts/tree/main/ofl/barlowcondensed — SIL Open Font License, see Barlow-OFL.txt.
- Noto Sans Arabic variable: https://github.com/google/fonts/tree/main/ofl/notosansarabic — SIL Open Font License, see NotoArabic-OFL.txt.

Downloaded 23 October 2026. Original font binaries are unmodified. English body text uses the platform Roboto family; headlines use Barlow. Arabic body and display text use Noto Sans Arabic.
